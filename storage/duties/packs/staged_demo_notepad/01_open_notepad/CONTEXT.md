# Stage 1 — Open Notepad

## Input
- Windows desktop available
- No prior Notepad required

## Process
1. Win+R → type `notepad` → Enter
2. Wait until a Notepad window is focused

## Output
- Notepad open and focused
- Write a short note to `output/handoff.md` (auto on run)

## Completion / human gate
**Stop for Approve** before stage 2. Human may rearrange windows or edit handoff notes, then Approve to continue.

VassalOps rule: stages decide where the human sits — never silent overnight desktop automation.
