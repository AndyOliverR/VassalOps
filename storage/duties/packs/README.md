# Demo duty packs

Safe, password-free sample duties you can import and run after **Approve**.

## Morning Notepad Briefing (killer vertical demo)

Goal: prove “type it / teach it → PC does it” in ~60 seconds without Outlook/SAP credentials.

1. Install & open VassalOps (`install_vassalops.ps1` once, then Desktop shortcut).
2. Chat: `import demo pack`
3. Chat: `run duty demo notepad hello` → **Approve**
4. Watch the progress panel (Stop / Continue if stuck).
5. Or teach your own: `teach morning email` → do the real task → Escape → `build my workday`.

Pack files live in this folder as JSON. `import demo pack` copies them into `storage/duties/`.

**Marketing spine:** *Your PC’s workday — taught by you, approved by you, run locally.*
