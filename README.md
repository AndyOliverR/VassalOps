VassalOps is a **local-first, universal desktop agent extension** designed to give users computing superpowers while keeping enterprise data 100% private. Built on top of a highly resilient web-wrapper UI, it shifts desktop execution away from fragile, hardcoded script sequences into a decoupled, self-improving metacognitive operational framework.

---

## 🔥 Key Product Features
- **Local-First Privacy:** Runs entirely on your local machine using an offline inference cluster node.
- **Minimalist Control Panel:** A clean, high-gloss interface featuring cached user customization drawers.
- **Universal Desktop Automation:** Emulates precise physical mouse movement coordinates and hardware keystrokes.
- **Ambient Self-Healing Pipeline:** Monitors its own execution traces to fix layout drift silently in the background.

---

## 🏗️ Core Agentic Architecture
VassalOps mirrors the advanced design choices utilized by enterprise-grade systems like the LangSmith Engine:

### 1. Model Context Protocol (MCP) Tool Isolation Layer
Tool execution is entirely detached from the core routing layer. All system utilities (directory backups, algorithmic data optimization streams) run within isolated environments via an **MCP Server Engine**, providing perfect crash isolation and runtime asset discoverability.

### 2. Multi-Agent Organizational Chart
Task delegation behaves exactly like a corporate org chart:
- **Main Director Agent (The Brain):** Coordinates data stream flows and manages asynchronous execution schedules.
- **Screener Sub-Agent (Fast & Low-Cost):** Ingests full, raw transaction timeline traces to scan for layout micro-anomalies.
- **Verifier Sub-Agent (Noise Gate):** Filters out minor non-critical warnings by parsing a long-term preference documentation schema.

### 3. Isolated Proving & Regression Bench
Before a proposed macro configuration patch is merged into your production pipeline, it is automatically stress-tested inside a stateful **Sandbox Mock Server**. The engine runs simulated variants against golden ground-truth evaluation datasets to prove updates pass without causing layout regressions.

### 4. Sleep-Time Compute & Memory Loop
VassalOps doesn't stop learning when you close the chat window. On an ambient background schedule, a specialized long-term memory engine analyzes trace metrics footprints to learn contextual preferences, writing optimization rules directly back to your persistent memory files.

## 🛠️ Quick Start Install Guide

### Prerequisites
Ensure your local environment has the required dependencies running:
```bash
# Install core physical device event interception listeners
pip install pyautogui pynput pywebview requests langgraph langchain
```

### Installation
1. Clone the repository tree cleanly to your local C drive setup:
   ```bash
   git clone https://github.com C:\VassalOps
   cd C:\VassalOps
   ```
2. Double-click **`VassalOpsLaunch.exe`** right inside your repository directory to boot the engine! The self-healing boot guard will quietly warm up your background server socket connections automatically.
